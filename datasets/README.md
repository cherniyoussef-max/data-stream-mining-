# Données

Le projet produit à la volée des flux uniformes, gaussiens, dérivants, constants, croissants, décroissants, répétitifs, à queue lourde, en rafales et binaires de Bernoulli. Le scénario de référence passe d’une latence centrée à 30 ms à 160 ms pendant le tiers central, puis revient à 30 ms. Aucun fichier de données réelles n’est utilisé.
