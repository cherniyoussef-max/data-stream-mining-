# Algorithmes du projet

Les deux réservoirs répondent à des questions sur l’ensemble du flux, DGIM compte les événements lents dans les N dernières positions, GK résume les rangs historiques, et les blocs pondérés estiment les rangs récents. Toutes les entrées utilisent les mêmes classes. Les [garanties](MATHEMATICAL_GUARANTEES.md) décrivent les conventions et les [exercices](MANUAL_EXERCISES.md) montrent les états internes.
