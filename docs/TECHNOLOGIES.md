# Outils utilisés et plateformes étudiées

| Usage local | Rôle observé dans le dépôt |
|---|---|
| Python et heapq | Résumés en une passe et tas minimum A-Res |
| pytest et SciPy | Assertions d’invariants et p-valeurs |
| Matplotlib et Streamlit | Figures expérimentales et interface de surveillance |
| Git et GitHub | Historique et collaboration |

Les plateformes ci-dessous servent à situer un déploiement futur. Le projet n’exécute aucune de ces plateformes.

| Plateforme | Rôle étudié | Documentation primaire |
|---|---|---|
| Kafka | Transport, publication, abonnement et conservation des événements | [Introduction Apache Kafka](https://kafka.apache.org/intro/) |
| Flink | Calcul réparti avec état, fenêtres et traitement en temps événementiel | [Applications Apache Flink](https://flink.apache.org/what-is-flink/flink-applications/) |
| Spark Structured Streaming | Calcul incrémental distribué via DataFrame et Spark SQL | [Guide Apache Spark](https://spark.apache.org/docs/latest/streaming/index.html) |
| Apache DataSketches | Bibliothèque de résumés pour quantiles, cardinalités et fréquences | [Apache DataSketches](https://datasketches.apache.org/) |
