# Animations scientifiques

Les 18 GIF sont incorporés dans le PowerPoint. Les quatre algorithmes, les blocs récents et le scénario de référence utilisent les classes du projet ou le CSV de simulation. Les fenêtres et les sept exemples d’articles sont illustratifs. `trace.json` enregistre les images et les états commentés. Les PNG sont les affiches finales employées par le PDF statique.

Génération depuis la racine avec `python -m presentation.animations.generate`.
